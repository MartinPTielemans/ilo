Go straight there
Search at the top, or /, then View all work items, then JQL beside the search icon, takes a query such as project = "KEY" AND assignee = currentUser() AND status IN ("To Do", "In Progress") ORDER BY created. ~ finds words in a text field such as the summary or the comments, IN stands for several ORs, and parentheses group.

Keys beat clicks
? lists every key. c makes a work item, o opens the one selected, a assigns it, i assigns it to the user and m adds a comment. j and k move down and up, n and p to the next and the previous column.

Know before you start
The user can turn Jira's keys off. If a key does nothing, click instead.
